# Project Zomboid preset

The ZIP contains `Project-Zomboid-Tartarus-V2-WheelFix-DPadTest.json`, a Linux Input Remapper preset.

The contributor has confirmed the full mapping works on their Razer Tartarus V2 with Pop!_OS, including the D-pad and wheel. The upper thumb Alt button is used for Hypershift, and the lower thumb paddle is Space.

Because Linux event origins may differ by device/system, back up your existing profile and verify the input event mapping before use. This is an **example preset**, not a universal one-click installer. The ZIP has no executable installer.

## Hypershift setup recommendation

Use the **upper thumb button (normally Alt)** as your Hypershift modifier, **not the large lower thumb paddle (button 20)**. If the thumb button also sends its original Alt keypress, disable/remove that original Alt binding in your remapper as needed to avoid conflicts or accidental shortcuts. Check conflicting in-game bindings too, and verify both layers after making changes.
